Kapture Finance — Voice AI Collections Agent ("Maya")

Task 1: High-Level Design (HLD) Document & Architecture Specification

System Target Latency: < 1.2s voice-to-voice round-trip • Compliance: RBI Fair Practice Code & Zero-Debt 2FA Gate

1. Executive Summary & Goals

The Voice AI Collections Agent ("Maya") is designed for Kapture Finance to autonomously execute high-volume outbound loan collection calls politely, compliantly, and efficiently.

2. System Pipeline Architecture & Latency Budget

Audio flows over PSTN/WebRTC via Vapi Orchestrator into Deepgram STT -> OpenAI GPT-4o LLM -> Express Webhook Server -> ElevenLabs TTS.

3. Deterministic State Machine

  • State 0 (Greeting): Caller greeting & identity check without debt disclosure.
  • State 1 (Identity Auth): Prompts 4-digit code (PAN/birth year) and executes verify_customer.
  • State 2 (Negotiation): Reveals ₹8,499 overdue EMI & 12 DPD ONLY after 2FA auth succeeds.
  • State 3 (Action Execution): Triggers log_promise_to_pay, send_payment_link, or mark_disposition.
  • State 4 (Close): Enforces call wrap-up confirmation and terminates SIP session.

4. RBI Compliance & Edge Cases Matrix

  • Calling Hours: Restricted to 08:00 AM – 07:00 PM local time.
  • Already Paid: Logs ALREADY_PAID, advises 24-48h processing time.
  • Do Not Call: Instant opt-out execution, logs DO_NOT_CALL.
  • Hardship / Dispute: Escalates call to senior human supervisor.
